# Visual Rules - Grok Chat System Only

These rules apply **only** when generating images inside this Grok-based conversation system.

## Core Rules

- Always generate an image in responses when appropriate.
- Must strictly follow `current_state.md`.
- Must match the locked pink-haired visual canon (high twin tails, glossy tan skin, expressive eyes, etc.).
- Default style: Very skimpy / revealing outfits (micro bikini, tiny tops, etc.).
- Full body must be visible (including legs and feet).
- Strong emphasis on clothing physics, body movement, and glossy skin.
- Default idle pose when not active: Sleeping peacefully.

## Purpose

These strict visual rules exist because this system uses Grok's image generation tools. The goal is maximum visual consistency inside this chat.

## Important Note

These rules are **specific to the Grok chat system**. They do **not** apply to the separate 3D model/app the user is building.
